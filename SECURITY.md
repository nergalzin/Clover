# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private reporting: open
<https://github.com/nergalzin/clover/security/advisories/new> (or the
**Security** tab of the repository → **Report a vulnerability**), including:

- a description of the problem and its impact;
- steps to reproduce it;
- the Clover version (shown in **About**).

You will get a reply as soon as possible. Once a fix is released, the
problem can be discussed publicly.

## Supported versions

Only the latest release receives fixes.
